# Modular Machinery Greggening

**Modular Machinery Greggening** is an addon to [Modular Machinery: Community Edition (MMCE)](https://www.curseforge.com/minecraft/mc-mods/modular-machinery-community-edition)
---

## • Features:

- **Advanced ME Item Input Bus**: Hatches that can interact and use nearby chunks.

---

## Issues & Feature Requests

If you encounter a bug or want to suggest a feature, please [open an issue](https://github.com/ming/MMCE-Greggening/issues).

---

## Installation

1. Download the mod from [CurseForge](https://legacy.curseforge.com/minecraft/mc-mods/modular-machinery-community-edition-addons).
2. Place the `.jar` file in your `mods` folder.
3. Make sure **Modular Machinery: CE** is installed.
